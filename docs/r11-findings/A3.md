# Wave-eleven A3：测试面修正（application/src/center_sync.rs）

区域：W11 代码落地的测试配套修正（commit eda3810）。

- **5 个旧测试的占位 digest 与存储字节不符**：W11-D-3 摘要校验使
  `ready_artifacts_are_distributed_as_manifest_and_chunks` /
  `a_truncated_artifact_file_leaves_no_half_set_and_heals` /
  `later_ready_artifacts_wait_for_the_broken_artifact` /
  `a_corrupt_artifact_cursor_resets_and_redistributes` /
  `a_failed_retire_escalates_into_the_round_error` 的占位 digest（`aaaa…` 等）
  与存储字节（`[0x01,0x02,0x03]` 等）不符，文件存在且满尺寸时被吸收、断言失败
  （4 个测试失败 + 升级测试同型隐患）。全部改为 `Sha256Hex::from_bytes(Sha256::digest(&bytes).into())`
  按真实字节哈希——「存储字节哈希到声明 digest」成为测试面统一不变量。
- **退休升级测试补缺**：armed-outbox helper（`set_fail_acknowledge`）自 W11 提交
  以来无调用方（dead code，clippy 暴露）；补 `a_failed_retire_escalates_into_the_round_error`：
  种子残留半套 + 武装 outbox → 退休 ack 失败 → `CenterSyncError::Outbox` 升级、
  半套存活不被吞。
- **三 lint 修复**：停滞臂 `ignored_unit_patterns`（`_ =` → `() =`）、`expect_used`
  （as_ref + let-else 绑定）、`clone_on_copy`（`*artifact_id`）。
- **heal 测试三层显式匹配**：`timeout(join(engine))` 的三层 Result
  （timeout → JoinError → 引擎自身错误）原 `??` 两层漏掉一层、`as_deref` 编译失败；
  现 `Ok(Ok(Ok(v)))` / `Ok(Ok(Err(e)))` / `Ok(Err(join_err))` / `Err(_)` 四臂显式。
