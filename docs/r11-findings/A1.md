# Wave-eleven A1：制品流收尾修复（application/src/center_sync.rs）

区域：站点侧制品分发与退休（`application/src/center_sync.rs`，commit eda3810）。
发现与修复逐项：

- **W11-P-1 吸收后停滞无界**：W10-D-1 的吸收让连接存活，但报告每连接只跑一次、
  心跳跨过所有空闲超时——稳定网络下重试永远不会到来。修复：停滞计时器在一个重连
  周期后主动结束连接（`ArtifactStreamStalled`），connect loop 的退避调度下一次重试。
- **W11-D-3 同尺寸摘要不符**：字节数与 manifest 一致但字节与声明 digest 不符的文件
  此前完整分发（错字节入库）。修复：reader 流式 SHA-256（多一次内存内哈希、零额外
  I/O），不符入吸收族（`ArtifactDigestMismatch` 带双摘要）。
- **W11-F-1 不可读文件**：目录占位符（PermissionDenied / IsADirectory）原走泛型读
  错误风暴。修复：`classify_artifact_read_error` 三态分类——持久不可读形状与缺文件
  同族吸收，瞬态族（EMFILE/ENFILE/Interrupted/WouldBlock）保持传播。
- **W11-F-2/C-2/C-3 派发台账**：`distribution_entries` 精确记录本次派发入队集合——
  退休只扫 fresh partial set（修「队列最老窗口被无关条目占满时退休够不到」的窗口
  突破）、零入队失败退休为空、退休失败升级为轮次错误绝不吞。
- **W11-S-1 内容行 ack 即删**：内容行 ack = 终态投递，生产仓库删除该行；退休路径
  复用同语义清理退休半套；offer 行保留 acked 历史（R6-E-04）不变。

顺带修复：停滞臂 `ignored_unit_patterns` / `expect_used` / `clone_on_copy` 三 lint
（`() = &mut stall` + as_ref 绑定 + 解引用）；heal 测试 timeout-join-result 三层显式
匹配（原 `??` 两层只到 `Result<Option<String>, _>`，as_deref 编译失败）。旧「缺文件
不拖连接」「瞬态读错误仍中止」2 测试被新 absorption/heal 与 classification 测试语义
覆盖后合并移除（center_sync 49→51：+4 新 −2 合并）。
