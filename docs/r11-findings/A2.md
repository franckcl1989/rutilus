# Wave-eleven A2：跨文档锚点机械门禁（scripts/check-doc-anchors.sh）

区域：docs/ 全部 `file:line` 引用的机械校验（commit d7f1a07 + 登记提交）。

十轮对抗审计反复暴露手工重锚的系统性漏检：wave-six 的 ci.yml +149/-62 推偏 ~+98
个锚点、五轮未被发现；wave-nine/ten 注释增长再推偏 +8/+11。门禁机械化该验证：

- **越界硬失败**：引用区间末行 > 文件长度即失败（exit 1）；
- **内容指纹 review 级**：doc 行与目标行的显著 token（≥5 字符）零共享时列出复核；
- **W11-T-2 裸 `:NNN` 续引**：继承同行最近的前序路径提及（完整锚点或背引号内裸
  路径），冒号须跟在分隔符后（`§0.9.0:2812` 之类散文永不误判）；
- **点-时登记豁免**：docs/r*-findings/ 按 W9-D-4「历史点-时登记保留原文」惯例豁免；
- **按文件行数缓存**：每引用文件只测一次行数（Windows 进程 spawn 慢，未缓存首跑
  957 引用需数分钟）。

**首跑战果**：抓出 6 处指纹级漂移（user-manual 的 BootstrapView/CenterSitesView/
EndpointCard/FamilyRequired 等落在无关行）+ 73 处此前完全不可见的裸续引越界（
ui/src/lib.rs 两次非均匀推偏 +104/+111、center_sync.rs 推偏、ci.yml 推偏），全部
按符号逐行核验重锚；ci.yml `Doc anchor gate` 步骤接入（+15 行）再推偏 34 处已同步
重锚。**终态：1130 引用全在界。**

门禁自身首轮暴露并修复两处盲区：①续行裸引（无完整锚点的行不可见——外层 grep
扩展）；②背引号内逗号续接数（`ci.yml:845-855, 870-879` 形式——awk 位移需 span
感知）。残余盲区如实登记于脚本头：token 共享漂移（漂到共享词汇的行指纹不报警）、
错路径继承（同行多文件时最近路径启发式）。
